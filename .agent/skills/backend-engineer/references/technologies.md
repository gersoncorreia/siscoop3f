# Backend Technologies (TALL Stack)

## 1. Core Stack
- **PHP:** 8.2+ (Typed, Readonly, Enums).
- **Laravel:** 11.x (Modern monolith/SaaS).
- **MySQL:** 8.0+ (Default DB with JSON/Spatial).
- **Redis:** 7.0+ (Caching and Queues).

## 2. Development & Tooling
- **Sail:** Dockerized environment.
- **Pint:** Zero-config PHP code styler (PSR-12).
- **Pest:** Modern PHP testing framework.
- **Vite:** Rapid frontend asset bundling.

## 3. Deployment & Scaling
- **Forge:** Automated server manager.
- **Envoy:** Remote task runner for deployments.
- **Octane:** High-speed server (Swoole).
- **Scribe:** Automated API documentation.

## 4. Secondary (Interoperability)
- **Node.js:** For Real-time (Soketi/Reverb) and Inertia.js SSR.
- **Python:** For specific ML/AI or intensive script tasks.
