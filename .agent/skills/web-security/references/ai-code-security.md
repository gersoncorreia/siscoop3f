# AI-Generated Code Security

## 1. Common AI Vulnerability Patterns
1. **Mass Assignment:** AI uses `$request->all()` or `$guarded = []`.
   - *Fix:* Use `$request->validated()` and strict `$fillable`.
2. **Missing Authorization:** AI adds middleware but forgets `Policy` checks.
   - *Fix:* Always call `$this->authorize()`.
3. **N+1 Data Leak:** AI eager-loads everything including PII.
   - *Fix:* Use API Resources to filter response fields.
4. **Hardcoded Secrets:** AI suggests API keys in `.env.example` or code.
   - *Fix:* Use `config('services.name.key')`.
5. **Debug Leftovers:** `dd()`, `dump()`, or `APP_DEBUG=true` in configs.
   - *Fix:* Search for debug statements before commit.

## 2. Secure AI Integration Checklist
- [ ] **No Raw Queries:** Replace AI's `DB::raw()` with Eloquent parameter binding.
- [ ] **Validation:** Ensure AI's validation rules are strict (mimes, max, type).
- [ ] **Rate Limiting:** Add `throttle` to public routes generated by AI.
- [ ] **XSS:** Verify use of `{{ }}` and `@json`.
- [ ] **Files:** Change AI's `public/` storage to private S3/Storage.

## 3. Review Protocol
1. Scan for `all()` or `guarded`.
2. Check for missing `authorize()` in controllers.
3. Validate `.env` usage (never use `env()` outside configs).
4. Verify PII encryption.
