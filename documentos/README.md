# 📚 Documentação do Projeto Siscoop3F

Esta pasta centraliza todas as documentações, guias de deploy, apresentações executivas e referências do projeto.

---

## 📁 Estrutura de Diretórios

### 1. 📊 apresentacao/
Arquivos da apresentação executiva desenvolvida para o corpo diretivo e conselho da cooperativa:
- `Apresentacao_Siscoop3F_Cooperativa.pptx`: Apresentação PowerPoint em formato 16:9 widescreen com transições animadas suaves entre slides.
- `apresentacao_cooperativa.html`: Versão web interativa para exibição em tela cheia via navegador (ideal para TVs e projetores).
- `roteiro_apresentador.md`: Guia e script do apresentador com o roteiro de fala e argumentos executivos para cada slide.

---

### 2. 🚀 deploy/
Manuais e guias de infraestrutura, implantação e servidores:
- `DEPLOY.md`: Instruções gerais de deploy do sistema.
- `GUIA_DEPLOY_HOSTINGER_VPS.md`: Passo a passo detalhado para deploy em VPS Hostinger.
- `SERVER_SETUP.md`: Configuração do ambiente de servidor (Nginx, PHP, PostgreSQL, Redis).
- `vps_docker_setup_guide.md`: Guia de configuração usando contêineres Docker em VPS.

---

### 3. 🔑 acessos_e_credenciais/
Registros de credenciais e rotas para testes e homologação local:
- `ACESSOS_LOCAL.md` e `ACESSO_LOCAL.md`: Mapeamento de portas, subdomínios dos tenants e acessos locais.
- `CREDENCIAIS_TESTE.md`: Usuários, perfis e senhas pré-configurados para testes nos portais.

---

### 4. 📝 prompts_e_tarefas/
Histórico de prompts de inicialização, escopos e anotações de backlog:
- `prompt-inicial.md` e prompts de integração.
- `task.md`: Checklist e notas de tarefas do desenvolvimento.
